Notes

  • Always add visually-hidden text to "Change" links so screen readers announce what is being changed (e.g. "Change name", not just "Change").
  • The <h1> is part of the component - do not add a separate page header above it.
  • Import summary_row from summary-block.j2 - check-answers does not re-export it.
  • Rows without actions (e.g. "Not provided") automatically get the summary-list-row-no-actions modifier, collapsing to a two-column grid.
  • The submit button defaults to btn-primary. Override with submit_kind="warning" for destructive actions.
