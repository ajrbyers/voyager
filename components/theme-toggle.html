Theme toggle

A small button that switches between light and dark mode. It sets the data-theme attribute on <html>, persists the choice in localStorage, and reflects its state via aria-pressed.

Default

The toggle below is live - pressing it switches this page's theme. The moon icon shows in light mode, the sun in dark mode, and the text label names the mode the button will switch to. 

<button type="button" class="theme-toggle" data-theme-toggle
        aria-label="Toggle dark mode" aria-pressed="false">

Behaviour

  • data-theme on <html> is the single source of truth. The toggle flips it between light and dark; CSS dark-mode aliases and the icon swap both key off this attribute.
  • aria-pressed reflects the state: true when dark mode is active, false otherwise. The aria-label stays "Toggle dark mode" while the visible label text swaps between "Dark" and "Light".
  • Persistence - the choice is stored under the localStorage key voyager-theme and read on the next page load. With no stored value, the prefers-color-scheme media query decides.
  • Event delegation - site.js binds one document-level click handler on [data-theme-toggle], so a page may carry several toggles (header, example banner) and all stay in sync.

Head script

Consumers must inline this script in <head>, before any stylesheet-dependent paint, so the stored theme is applied without a flash of light content. The localStorage access is wrapped in try/catch because storage can throw in private browsing modes or when blocked by policy - the toggle then falls back to the system preference. 

<script>(function(){var k='voyager-theme',d=window.matchMedia('(prefers-color-scheme: dark)').matches,t=null;try{t=localStorage.getItem(k)}catch(e){}document.documentElement.setAttribute('data-theme',t||(d?'dark':'light'));})();</script>

Notes

  • The button uses currentColor for its border and inherits its text colour, so it adapts to its surroundings - white on dark headers, black on the yellow example banner - with no per-context variants.
  • Both icons are aria-hidden="true"; state is conveyed by aria-pressed and the label text, not by the icon alone.
  • The button meets the WCAG 2.2 minimum target size (SC 2.5.8) via its 24px minimum height.
  • Without JavaScript the toggle does nothing, but the head script still applies the system preference - dark-mode users are never flashed with a light page.
