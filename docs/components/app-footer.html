App footer

A modest meta strip at the bottom of every admin page: version on the left, a help link on the right.

Example

Place it as the last child of .app-shell-main so it sits beneath the page content - see the Application shell page for the full layout. Keep the footer light: version and a help link. It is not the place for navigation or legal boilerplate.
