Breadcrumbs

A trail of links showing where the current page sits in the hierarchy. Place it above the page title, with the current page as the final, unlinked item.

Example

  1. Dashboard
  2. Articles
  3. #1247 Okafor
  4. Peer Review
<nav class="breadcrumbs" aria-label="Breadcrumb">
  <ol>
    <li><a href="/">Dashboard</a></li>
    <li><a href="/articles">Articles</a></li>
    <li><a href="#"><span class="mono">#1247</span> Okafor</a></li>
    <li aria-current="page">Peer Review</li>
  </ol>
</nav>
{% from "voyager/components/breadcrumbs/breadcrumbs.j2" import breadcrumbs, breadcrumb %}

{% call breadcrumbs() %}
  {{ breadcrumb("Dashboard", url="/") }}
  {{ breadcrumb("Articles",  url="/articles") }}
  {{ breadcrumb("#1247 Okafor", url="#") }}
  {{ breadcrumb("Peer Review", current=True) }}
{% endcall %}
