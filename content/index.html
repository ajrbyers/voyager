Voyager

Voyager is Janeway's design system. It provides components for editorial work, including submission lists, review screens, and forms.

Design principles

Voyager uses established interface patterns to support accessible editorial workflows. Many of its forms and components are adapted from the GOV.UK Design System.

How it's organised

  • Foundations - colours, typography, spacing, and page layouts.
  • Components - reusable interface elements with CSS, Jinja macros, and usage examples.
  • Examples - an editorial dashboard, manager index, and peer-review screen. These pages use handwritten component markup and additional page styles.

How to use it

Load Voyager's stylesheet and JavaScript entry points in your page's <head>. In a Django project with the voyager app installed, use the static tag:

<link rel="stylesheet" href="{% raw %}{% static 'voyager/assets/css/index.css' %}{% endraw %}">
<script type="module" src="{% raw %}{% static 'voyager/assets/js/index.js' %}{% endraw %}"></script>

Then use the component HTML or call the Jinja macros. Every component page shows both forms, with a rendered preview:

{% set src %}{% raw %}{% from "voyager/components/tag/tag.j2" import tag %} {{ tag("Under review", kind="green") }} {{ tag("Article", kind="grey") }}{% endraw %}{% endset %} {{ example(src) }}

See Installation for adding the app to a Django project and configuring static-file hashing, and Loading styles for how the stylesheet is put together.

Architecture

Voyager follows Memory Alpha's CSS structure. It uses custom properties for design tokens, native nesting for component styles, and separate classes for variants. See Architecture for the file structure and styling conventions.
