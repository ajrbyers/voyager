Section divider

Use a section divider to label groups in a list, such as urgent submissions, administration categories, or dates in a timeline.

Default

The heading text sits on the left, and a thin line fills the rest of the row.

{% set src %}{% raw %}{% from "voyager/components/section-divider/section-divider.j2" import section_divider %} {{ section_divider("Journal settings · 5", flush=True) }} {{ section_divider("Review · 2") }}{% endraw %}{% endset %} {{ example(src) }}

With severity dot

A coloured dot can reinforce a status named in the heading. The heading text must explain the status.

{% set src %}{% raw %}{% from "voyager/components/section-divider/section-divider.j2" import section_divider %} {{ section_divider("Critical · 2", kind="critical", flush=True) }} {{ section_divider("Warning · 2", kind="warning") }} {{ section_divider("Info · 1", kind="info") }} {{ section_divider("All clear · 1") }}{% endraw %}{% endset %} {{ example(src) }}

Notes

  • The label is an <h2>. Use it at the corresponding level in the page's heading structure.
  • Use section-divider-flush for the first divider in a list to remove the top margin.
  • The dot carries no meaning on its own. Name the status or the count in the label.
