Page header

The page header contains the page title and optional context, including an article ID, author details, dates, and status tags.

Default

Use the caption for context, the title for the page heading, and the byline for related people or dates. Add tags when a status or category helps identify the content.

{% set src %}{% raw %}{% from "voyager/components/page-header/page-header.j2" import page_header %} {% from "voyager/components/tag/tag.j2" import tag %} {% call page_header( caption_prefix="Article", caption_chip="#1247", caption_suffix="· Peer review", title="Reproducibility of LSTM forecasts for short-term electricity demand", byline_lead="Dr Adaeze Okafor", byline="University of Lagos · submitted 4 March 2026" ) %} {{ tag("Under review", kind="green") }} {{ tag("Round 2 of 2", kind="grey") }} {{ tag("Article", kind="grey") }} {% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Without tags

The caption, byline, and tags are optional. The title is required.

{% set src %}{% raw %}{% from "voyager/components/page-header/page-header.j2" import page_header %} {{ page_header( title="Manager", byline="Settings, content, and workflow configuration for the journal." ) }}{% endraw %}{% endset %} {{ example(src) }}

Placement

Place the page header inside the main content column, not in the app header. With .layout-with-rail, the title sits beside the rail's first section, so both columns start at the same vertical position.

Accessibility

  • The title is the page's only <h1>.
  • The caption is a span rather than a heading, because it provides context rather than a level in the heading structure.
  • Write the status in the tag's text so that its meaning does not depend on colour.
