Button

Use buttons for actions such as saving a draft, submitting a review, or withdrawing a submission. Choose the variant according to the action's importance and consequences.

Choosing a variant

  • Default (grey) - use for supporting actions, such as Save draft or Send reminder.
  • Primary (green) - use for the page's main action, such as Submit review.
  • Warning (red) - use for destructive actions, such as Withdraw submission.

Sizes

Size modifiers combine with any variant. Use btn-small for table-row actions and dense toolbars, where the default size is too tall.

Button group

Group related actions together. For buttons with long labels, use .btn-group-vertical to place them on separate lines.

Disabled state

Pass disabled=True to disable a button. If you also pass href, the macro renders a placeholder without a destination: an <a> with no href, the is-disabled class, and aria-disabled="true". Explain why the action is unavailable when that is not clear from the surrounding content.

Accessibility

  • Use type="button" for buttons that do not submit a form.
  • Use a <button> element for an action, rather than a <div> with a click handler.
  • Focus styling comes from the global yellow focus rule. Do not override it on individual buttons.
