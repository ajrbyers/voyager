Remembers open state

Add data-details-persist="<key>" to remember whether the section is open. The browser stores the choice in localStorage, under voyager-details:<key>. Until a choice is stored, the section uses the state rendered by the server. Sections with the same key share that preference.

Notes

  • Name the contents in the summary, such as Review history or Additional files, so users can decide whether to open it.
  • The macro wraps the native <details> and <summary> elements, so the disclosure works without JavaScript.
  • Use data-details-persist for long-lived disclosures such as file lists or expanded panels. Do not use it for help text, validation messages, or anything that should reset on each page load.
