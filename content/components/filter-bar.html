Filter bar

Use a filter bar to narrow a list of results. Active filters appear below the controls, with a link to remove each one. Clear filters removes all selections.

Notes

  • Your application handles filter changes, either by submitting the form or sending an HTMX request. Voyager provides the controls and their styling.
  • Use filter_input (class filter-input) for text, date, and number fields so they align with the select controls. Do not use full-size form-input controls in a filter bar.
  • Each chip's remove link removes only its own filter and preserves the others.
  • Hide the chips row when no filters are active. An empty filter-bar-chips collapses to zero height.
  • Pair with the folder list and article card for the inbox-style dashboard.
