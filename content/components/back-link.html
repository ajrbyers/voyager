Back link

Use a back link to return to a related list, such as the peer-review queue. Place it above the page content and name its destination.

Default

{% set src %}{% raw %}{% from "voyager/components/back-link/back-link.j2" import back_link %} {{ back_link("Back to peer review queue", url="/inbox?folder=peer_review") }}{% endraw %}{% endset %} {{ example(src) }}

Notes

  • Name the destination in the link text, such as Back to peer review queue rather than Back.
  • Set an explicit destination rather than javascript:history.back(). Browser history may lead somewhere unexpected when a user opens the page from an external link.
  • Pair the back link with breadcrumbs only when the breadcrumbs provide additional context. On most editorial detail pages a back link alone is enough.
