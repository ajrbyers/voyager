Icon

Voyager provides SVG icons for actions and navigation. Icons inherit the surrounding text colour through currentColor.

Every icon uses a 24×24 viewBox, a 2 px stroke width, and round caps and joins. The icons follow the Lucide style.

Library

The library contains 50 icons. Use the name below each icon when calling the icon() macro. Select an icon to copy its name.

Sizing

The base .icon class sizes to 1em, so the icon scales with the surrounding font size. Use a size modifier to set an explicit size.

{% set src %}{% raw %}
icon-sm 14px icon-md 18px icon-lg 24px icon-xl 32px
{% endraw %}{% endset %} {{ example(src, jinja=False) }}

Inside other components

Components set icon sizes to suit their layout: 14 px inside a button, and 13 px inside an action-menu icon tile or a sidebar navigation link. Use an explicit size modifier when placing an icon outside those components.

Accessible names

When an icon repeats an adjacent text label, hide it from assistive technology with aria-hidden="true".

Give buttons and links that contain only an icon an accessible name, such as aria-label="Open menu". Pass title to the macro to give a standalone icon its own accessible name.

{% set src %}{% raw %}{% from "voyager/components/icon/icon.j2" import icon %} {{ icon("file") }} Manage files {{ icon("alert", title="Critical") }}{% endraw %}{% endset %} {{ example(src) }}

Notes

  • Use an SVG icon rather than a unicode glyph (☎ ⚙ ✓). Unicode glyphs render inconsistently across systems.
  • Don't fill icons with a colour. They use fill: none and stroke currentColor; colour them via color on the parent.
  • Don't mix stroke widths within a page. 2 px is the system default; small variants use 2.2 or 2.4 for visual weight at 12–14 px.
  • To add an icon, add its SVG paths to the _ICONS dictionary in components/icon/icon.j2. The macro reads its names from that dictionary.
