Table

Use a table for genuinely tabular data - rows of similar records with the same columns. For key/value detail like an article's metadata, reach for a summary list instead.

Notes

  • Always use <th> for column headers - screen readers announce them when navigating cells.
  • Right-align action cells with the .right utility for consistent table action styling.
  • Generic "Download" / "Edit" links need a visually-hidden suffix to disambiguate when listed out of context.
