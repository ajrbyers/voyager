Notes

  • Give each Change link an accessible name that identifies the answer, such as Change name. Add the identifying text with .visually-hidden when necessary.
  • The <h1> is part of the component - do not add a separate page header above it.
  • Import summary_row from summary-block.j2 - check-answers does not re-export it.
  • Rows without actions, such as "Not provided", get the summary-list-row-no-actions modifier, which collapses the row to a two-column grid.
  • The submit button defaults to btn-primary. Override with submit_kind="warning" for destructive actions.
