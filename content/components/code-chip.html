Code chip

An inline monospaced label for IDs, branch names, and SHAs. Use it for article IDs, revision numbers, and file names in prose.

Example

{% set src %}{% raw %}{% from "voyager/components/code-chip/code-chip.j2" import code_chip %} Article {{ code_chip("#1247") }} · revision {{ code_chip("R-2026-091") }} · branch {{ code_chip("main") }}{% endraw %}{% endset %} {{ example(src) }}

Notes

  • Code chips are inline text, not interactive elements. For status labels, use a tag instead.
