Item list

Use an item list when a form contains repeated entries, such as authors or references. Users can add or remove entries up to the configured limit.

With htmx_url, the component updates the list through HTMX. Without it, the buttons submit the form and your application handles the requested change.

Default

{% set src %}{% raw %}{% from "voyager/components/item-list/item-list.j2" import item_list, item_list_item %} {% from "voyager/components/form/form.j2" import form_text %} {% call item_list(name="authors", item_label="Author", count=2, max_items=10, htmx_url="/api/authors") %} {% call item_list_item(0, "authors", "Author", show_delete=False, htmx_url="/api/authors") %} {{ form_text("author_name_0", "author_name_0", "Name") }} {{ form_text("author_email_0", "author_email_0", "Email", type="email") }} {% endcall %} {% call item_list_item(1, "authors", "Author", htmx_url="/api/authors") %} {{ form_text("author_name_1", "author_name_1", "Name") }} {{ form_text("author_email_1", "author_email_1", "Email", type="email") }} {% endcall %} {% endcall %}{% endraw %}{% endset %} {{ example(src) }}

With errors

{% set src %}{% raw %}{% from "voyager/components/item-list/item-list.j2" import item_list, item_list_item %} {% from "voyager/components/form/form.j2" import form_text %} {% call item_list(name="patents", item_label="Patent", count=2, max_items=5, htmx_url="/api/patents", errors=["Patent 1: Enter a patent title", "Patent 2: Enter a patent number"]) %} {% call item_list_item(0, "patents", "Patent", show_delete=False, htmx_url="/api/patents") %} {{ form_text("patent_title_0", "patent_title_0", "Title", error="Enter a patent title") }} {% endcall %} {% call item_list_item(1, "patents", "Patent", htmx_url="/api/patents") %} {{ form_text("patent_number_1", "patent_number_1", "Number", error="Enter a patent number") }} {% endcall %} {% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Maximum number of items

When count equals max_items, the macro hides the add button and the remaining count.

{% set src %}{% raw %}{% from "voyager/components/item-list/item-list.j2" import item_list, item_list_item %} {% from "voyager/components/form/form.j2" import form_text %} {% call item_list(name="refs", item_label="Reference", count=3, max_items=3, htmx_url="/api/refs") %} {% call item_list_item(0, "refs", "Reference", htmx_url="/api/refs") %} {{ form_text("ref_0", "ref_0", "URL", type="url", value="https://doi.org/10.1234/abc") }} {% endcall %} {% call item_list_item(1, "refs", "Reference", htmx_url="/api/refs") %} {{ form_text("ref_1", "ref_1", "URL", type="url", value="https://doi.org/10.5678/def") }} {% endcall %} {% call item_list_item(2, "refs", "Reference", htmx_url="/api/refs") %} {{ form_text("ref_2", "ref_2", "URL", type="url", value="https://doi.org/10.9012/ghi") }} {% endcall %} {% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Notes

  • Pass the same name, item_label, and htmx_url to item_list() and to each item_list_item(). Jinja macros have isolated scopes, so the items cannot read the list's values.
  • Set show_delete=False on the first item when count == 1. The macro cannot count its siblings, so the caller decides when to show the delete button.
  • The HTMX endpoint accepts a POST and returns the complete <div class="item-list"> element, which is swapped in with outerHTML. The hidden count and max fields are sent with the request through hx-include.
  • With htmx_url, the add and delete controls are type="button" elements that depend on HTMX. They do nothing without JavaScript, so the component has no automatic fallback in this mode.
  • Without htmx_url, the controls are type="submit" buttons with a name and value pair (name-action=add or name-action=delete-N), so your application can handle the change from a standard form POST.
  • Each delete button includes visually-hidden text naming its item, such as Delete author 2, so its accessible name identifies the entry it removes.
