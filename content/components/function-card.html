Function card

A function card links to an administration tool or settings page. It includes a title, a short description, an icon, and optional counts and category tags. The Manager page arranges function cards in a grid.

Default

The card shows an icon, a count, a title, a description, tags, and an arrow. On hover, the card lifts and the arrow shifts to the right.

Icon colour pool

Use the same icon colour for tools in the same category. Nine colours are available: blue, green, orange, purple, pink, teal, red, yellow, and grey.

The is-coming-soon variant dims the card, removes its link, and shows a yellow "Coming soon" badge in place of the count.

Filtering

For client-side filtering with function-filter, each card carries three data attributes that the script matches against:

  • data-title - the lowercase title, for text search.
  • data-desc - the lowercase description, for text search.
  • data-tags - space-separated category tags, for the tag filter.

The macro sets all three. The rendered HTML below shows them on the card element.

Notes

  • The card is an <a> element, so it is focusable and keyboard-accessible.
  • Describe what the user can do on the destination page. Keep the description brief, to one line where possible, because the card has a minimum height that keeps rows aligned.
  • Include a count when it helps users understand the destination, such as the number of review forms. Otherwise, omit it.
