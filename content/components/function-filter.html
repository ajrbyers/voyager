Filtering with JavaScript

The example script filters cards by their title, description, and category. It hides cards that do not match, reading data-title, data-desc, and data-tags from each function card.

{% set src %}{% raw %}(function () { var form = document.getElementById('manager-filter'); var search = document.getElementById('mgr-search'); var grid = document.getElementById('manager-grid'); var empty = document.getElementById('manager-empty'); function activeTag() { var c = form.querySelector('input[name="tag"]:checked'); return c ? c.value : 'all'; } function apply() { var q = (search.value || '').trim().toLowerCase(); var tag = activeTag(); var anyVisible = false; grid.querySelectorAll('.function-card').forEach(function (card) { var title = (card.dataset.title || '').toLowerCase(); var desc = (card.dataset.desc || '').toLowerCase(); var tags = (card.dataset.tags || '').toLowerCase().split(/\s+/); var matchTag = tag === 'all' || tags.indexOf(tag) !== -1; var matchText = !q || title.indexOf(q) !== -1 || desc.indexOf(q) !== -1; card.hidden = !(matchTag && matchText); if (!card.hidden) anyVisible = true; }); empty.hidden = anyVisible; } search.addEventListener('input', apply); form.addEventListener('change', apply); })();{% endraw %}{% endset %} {{ example(src, jinja=False) }}

HTMX alternative

For filtering on the server, pass the endpoint as action and the results container as htmx_target.

{% set src %}{% raw %}{% from "voyager/components/function-filter/function-filter.j2" import function_filter, function_filter_search, function_filter_tags, function_filter_tag %} {% call function_filter(action="/manager/dashboard", htmx_target="#manager-grid") %} {{ function_filter_search(name="query") }} {% call function_filter_tags() %} {{ function_filter_tag("tag", "all", "All", checked=True) }} {{ function_filter_tag("tag", "settings", "Settings") }} {% endcall %} {% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Notes

  • The chips are radio inputs. Their active state comes from CSS (:has(input:checked)) and needs no JavaScript.
  • Wrap the radio group in a div role="radiogroup" with an aria-label so screen readers announce it as a group.
  • Pair every filter row with a function-filter-empty block that is hidden by default, and show it when no cards match, either from the script or from the server response.
