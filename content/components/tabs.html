Tabs

A row of navigation links where each tab is a different filtered view of the same page. Use tabs when the views share one underlying list, such as review rounds or workflow states.

Filter tabs

Real navigation links - each tab is a different filtered view. Use aria-current="true" on the active link, not role="tab" (this is not an ARIA tabs widget).
