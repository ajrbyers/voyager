Progress bar

A progress bar provides a visual indication that a request is running. It is a 3 px strip fixed to the top of the page. Provide a text status message as well, because the bar carries no information on its own.

Try it

The markup example below renders one progress bar, fixed to the top of this page. Select Trigger progress bar to run the start and finish animation.

Connecting to HTMX

Start the bar when a request begins and finish it when the response settles. The animation advances to 85% while the request runs, then completes and fades out once the response has settled. It does not measure how much of the request is complete.

{% set src %}{% raw %}const bar = document.getElementById('progress-bar'); function start() { bar.style.transition = 'none'; bar.style.width = '0%'; bar.classList.add('is-running'); requestAnimationFrame(() => requestAnimationFrame(() => { bar.style.transition = 'width 8s cubic-bezier(0.1, 0.05, 0, 1)'; bar.style.width = '85%'; })); } function done() { bar.style.transition = 'width 0.15s ease'; bar.style.width = '100%'; setTimeout(() => { bar.classList.remove('is-running'); bar.style.width = '0%'; }, 250); } document.body.addEventListener('htmx:beforeRequest', start); document.body.addEventListener('htmx:afterSettle', done); document.body.addEventListener('htmx:responseError', done);{% endraw %}{% endset %} {{ example(src, jinja=False) }}

Notes

  • The bar is aria-hidden="true". Announce loading state from a live region on the content that is changing, not from the bar.
  • Show the bar only for the request that loads the content concerned. Compare evt.detail.target with the target element before starting it.
  • Use cubic-bezier(0.1, 0.05, 0, 1) for the first phase so the bar slows as it approaches 85% and does not reach the end before the response arrives.
