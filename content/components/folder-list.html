Folder list

A folder list groups workflow queues and saved views in a sidebar. Each item has a name, an icon, and an optional count. Folders are arranged in labelled sections, and user-created folders show a colour dot with edit and delete buttons.

At widths of 900px or less, users can expand the list with Folders. The shared disclosure script in folder-list.js controls the expanded state through data-disclosure-toggle, aria-controls, and aria-expanded.

Notes

  • Use the count to show how many articles a folder contains. If colour indicates urgency, explain that urgency in text as well.
  • The active folder gets aria-current="page" so screen readers announce it.
  • The actions on a user-created folder appear on hover, or when focus moves into the row.
  • The search input uses the standard .form-input class - no special styling needed.
