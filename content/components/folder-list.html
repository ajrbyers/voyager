Folder list

Sidebar navigation for inbox-style pages. Groups folders into labelled sections, each item carries an icon, name, and optional count. Counts can be coloured to flag critical or warning severity. Custom (user-created) folders show a colour dot and inline edit/delete affordances on hover. Below 900px the folder tree collapses behind the Folders button beside the search input; the shared disclosure driver in folder-list.js toggles it via data-disclosure-toggle, aria-controls and aria-expanded.

Notes

  • Counts use coloured backgrounds for critical/warning state, never colour alone - the count number is the primary signal; severity is supplementary.
  • The active folder gets aria-current="page" so screen readers announce it.
  • Custom folder actions are visually hidden until hover (or keyboard focus inside the row).
  • The search input uses the standard .form-input class - no special styling needed.
