Application shell

The application shell places journal navigation beside the main content. Use it for editorial and administration screens.

App shell

Place .app-shell after the app header. Put the sidebar nav first and <main class="app-shell-main"> second.

Use .layout-full or .layout-with-rail (see the Rail page) inside the main element to arrange the content and add spacing. At widths of 900px or less, the shell uses one column. The peer review example shows the shell on a complete page.

When to use

  • Use the app shell on signed-in administration screens, such as dashboards, workflow pages, and manager pages.
  • Do not use it on public-facing or reading pages, which have their own layouts.
  • Use one shell per page. Nesting shells or adding further columns at this level breaks the single-column layout on narrow screens; use .layout-with-rail inside the main element instead.

Notes

  • Give the main element id="main" so the skip link can target it.
  • The sidebar column width comes from the --shell-sidebar-width token. Override it at page level if a screen needs a wider sidebar.
  • The footer at the end of the main element is documented on the App footer page.
