Queue card

A bordered card with a header, a stack of stats, and an "Open queue" CTA at the foot. Use it to represent a single workflow queue on the dashboard.

Example

{% set src %}{% raw %}{% from "voyager/components/queue-card/queue-card.j2" import queue_card %} {% from "voyager/components/stat/stat.j2" import stat %} {% call queue_card("Editor queue", tag={"label": "Editor", "kind": "grey"}, cta={"label": "Open queue", "url": "/editor"}) %} {{ stat(7, "Unassigned articles", kind="critical") }} {{ stat(14, "In peer review") }} {{ stat(3, "Decisions ready", kind="success") }} {% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Notes

  • Stats stack vertically inside a queue card. Each consecutive stat gets a top border to separate the rows.
