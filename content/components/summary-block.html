Summary block

Use a summary block to group related facts and actions. It contains a heading and a body, which often holds a summary list.

With summary list

Each row contains a label, a value, and an optional action such as Change.

Reviewer variant

Place the review status beside the reviewer's name. Use summary-block-clean to remove the header background.

Status rail variants

Apply one of summary-block-rail-green, summary-block-rail-orange, or summary-block-rail-red to add a 4px coloured left border. Use the border to reinforce the status shown in the heading, and include a text label that explains the status.

Notes

  • The title is an <h2>, so summary blocks sit under the page's <h1>.
  • Set aria-labelledby on the section to the title's id so screen readers announce the block by name.
  • Use summary-block-body-flush when the body is a summary list - it removes the body padding so the list rows go edge-to-edge.
