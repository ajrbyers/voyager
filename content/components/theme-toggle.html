Theme toggle

The theme toggle switches between light and dark mode and saves the preference in the browser.

Default

Select Dark or Light to change this page's theme. The label names the mode the button will activate. The moon icon shows in light mode and the sun icon in dark mode.

{% set src %}{% raw %}{% from "voyager/components/theme-toggle/theme-toggle.j2" import theme_toggle %} {{ theme_toggle() }}{% endraw %}{% endset %} {{ example(src) }}

Behaviour

  • data-theme on <html> is the single source of truth. The toggle flips it between light and dark; the CSS dark-mode aliases and the icon swap both key off this attribute.
  • aria-pressed reflects the state: true when dark mode is active, false otherwise. The aria-label stays "Toggle dark mode" while the visible label text swaps between "Dark" and "Light".
  • Persistence - the choice is stored under the localStorage key voyager-theme and read on the next page load. With no stored value, the prefers-color-scheme media query decides.
  • Event delegation - theme-toggle.js binds one document-level click handler on [data-theme-toggle], so a page may carry several toggles (header, example banner) and all stay in sync.

Head script

Add this script to the page's <head> to apply the saved theme before the page is displayed. If no preference is saved, it uses the device's colour-scheme preference. The localStorage access is wrapped in try/catch because storage can throw in private browsing modes or when blocked by policy; the script then uses the device preference.

Notes

  • The button uses currentColor for its border and inherits its text colour, so it adapts to its surroundings - white on dark headers, black on the yellow example banner - with no per-context variants.
  • Both icons are aria-hidden="true"; the state is conveyed by aria-pressed and the label text, not by the icon alone.
  • The button meets the WCAG 2.2 minimum target size (SC 2.5.8) through its 24px minimum height.
  • Without JavaScript, the toggle is inactive and Voyager uses its default light theme.
