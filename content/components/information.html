Information

Use a notice for a status message, inset text for supporting information, and an error summary for form validation errors. Use warning text to explain the consequences of a serious action.

Notice - info (default)

{% set src %}{% raw %}{% from "voyager/components/information/information.j2" import notice %} {% call notice("Reviewer response overdue") %}

Reviewer #419 has not responded to the invitation sent on 12 April 2026, 28 days ago.

{% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Notice - variants

Add .notice-warning, .notice-error, or .notice-success alongside .notice.

{% set src %}{% raw %}{% from "voyager/components/information/information.j2" import notice %} {% call notice("Action needed", kind="warning") %}

Revision R-2026-091 is 4 days overdue.

{% endcall %} {% call notice("Decision not saved", kind="error") %}

The decision could not be saved. Try again. If the problem continues, contact support.

{% endcall %} {% call notice("Decision sent", kind="success") %}

Your decision letter was emailed to the corresponding author.

{% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Inset text

Inset text separates supporting information from the surrounding content without adding a heading. It suits a short status summary in the rail.

{% set src %}{% raw %}{% from "voyager/components/information/information.j2" import inset_text %} {% call inset_text() %}

Currently in Under review. A request for minor revisions is open.

You can make a decision after another review is received.

{% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Error summary

Use an error summary at the top of a form when validation fails. Each error is a link that moves focus to the field it describes. The summary carries role="alert"; how a screen reader announces it depends on the browser and screen reader, and on when the summary appears.
