Information

Three patterns for surfacing status messages, in the order they appear below: notice for events worth surfacing, inset text for ambient context, and error summary for failed form submissions. For serious or irreversible actions, see warning text.

Notice - info (default)

{% set src %}{% raw %}{% from "voyager/components/information/information.j2" import notice %} {% call notice("Important") %}

Reviewer #419 has not acknowledged the invitation sent on 12 April 2026.

{% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Notice - variants

Add .notice-warning, .notice-error, or .notice-success alongside .notice.

{% set src %}{% raw %}{% from "voyager/components/information/information.j2" import notice %} {% call notice("Action needed", kind="warning") %}

Revision request R-2026-091 is overdue by 4 days.

{% endcall %} {% call notice("Something went wrong", kind="error") %}

The decision could not be saved. Try again or contact support.

{% endcall %} {% call notice("Decision sent", kind="success") %}

Your decision letter was emailed to the corresponding author.

{% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Inset text

Quiet ambient context. No header. Use in the right rail under "Status".

{% set src %}{% raw %}{% from "voyager/components/information/information.j2" import inset_text %} {% call inset_text() %}

Currently in Under Review. An active minor revision is in flight.

{% endcall %}{% endraw %}{% endset %} {{ example(src) }}

Error summary

Used at the top of a form when validation fails. Each error is a link that focuses the corresponding field. role="alert" announces the summary to screen readers immediately.

{% set src %}{% raw %}{% from "voyager/components/information/information.j2" import error_summary, error_summary_item %} {% call error_summary() %} {{ error_summary_item("Enter a decision letter to send to the author", anchor="decision-letter") }} {{ error_summary_item("Choose a decision", anchor="decision-kind") }} {% endcall %}{% endraw %}{% endset %} {{ example(src) }}
