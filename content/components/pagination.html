Pagination

Use pagination to move through a list that spans several pages, such as articles, users, news posts, or the email log. Place it below the results.

Default

{% set src %}{% raw %}{% from "voyager/components/pagination/pagination.j2" import pagination %} {{ pagination( prev_url="?page=4", prev_label="Page 4", next_url="?page=6", next_label="Page 6", pages=[ {"n": 1, "url": "?page=1"}, {"ellipsis": True}, {"n": 4, "url": "?page=4"}, {"n": 5, "current": True}, {"n": 6, "url": "?page=6"}, {"ellipsis": True}, {"n": 12, "url": "?page=12"}, ] ) }}{% endraw %}{% endset %} {{ example(src) }}

Notes

  • For long lists, show the first page, last page, current page, and nearby pages. Use an ellipsis for omitted ranges.
  • The macro marks the current page with aria-current="page", adds rel="prev" and rel="next" to the previous and next links, and wraps the controls in <nav aria-label="Pagination">. Keep those attributes if you write the markup by hand.
  • On the first page, omit Previous. On the last page, omit Next.
