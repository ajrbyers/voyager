Typography

Voyager uses fonts installed on the user's device. It provides a Helvetica/Arial stack, a system font stack, and a monospace stack for identifiers and code. Body text and buttons use the Helvetica/Arial stack. Navigation and dense data components - the app header, sidebar nav, tabs, breadcrumbs, tables, and the app footer - use the system font stack. Code, IDs, file names, and commit hashes use the monospace stack.

Type stacks

  • --font-sans - body and content. "Helvetica Neue", "Arial", sans-serif
  • --font-system - navigation and dense data. -apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial, sans-serif
  • --font-mono - code, IDs, files. ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace

Scale

Use the type scale to distinguish page titles, section headings, body text, and supporting information.

--fs-display 32pxEditorial decision
--fs-h1 24pxReproducibility of LSTM forecasts
--fs-h2 18pxReviewers
--fs-h3 16pxFiles in Round 2
--fs-lg 16pxLarge body text - introductory paragraphs
--fs-md 15pxBody medium - button labels
--fs-base 14pxBody - the default size for paragraphs and tables
--fs-sm 13pxBody small - sidebar links, breadcrumbs
--fs-xs 12pxCard metadata, alert pills, and filter labels

Weights

  • 700 - headings and form labels
  • 600 - table header cells, the current sidebar link, and other active states
  • 500 - app-header navigation links, page-header captions, and small counts
  • 400 - body text and button labels

Line height

  • --lh-tight 1.25 - headings
  • --lh-base 1.5 - body
